# RD-Agent 的模型研究能力與比賽適用性

2026-10-25

**結論**：RD-Agent 可以做模型研究，例如 LightGBM 和各種神經網路，但不適合拿來趕 10/27 開賽或 11/2 的 v1.1。原因有五個：
- 模型迴圈的評分方式跟比賽對不上。
- 可用的資料量小。
- 近半年行情反轉，模型會學到已經失效的關係。
- 模型的選股理由難寫進 D-Plan。
- 時間不夠。

比較可行的是：比賽期間用 LightGBM 當「因子組合器」做紙上追蹤，當作之後的研究。

## 1. RD-Agent 能做哪些模型研究

RD-Agent 跟量化有關的迴圈有三種：

| 迴圈 | 做什麼 | 本 repo 的入口 |
|---|---|---|
| 因子迴圈 | LLM 提出因子、寫因子程式 | `factor_tw.py`；比賽版 `alpha_tw.py` |
| 模型迴圈 | LLM 提出模型架構、寫 PyTorch 模型程式 | `model_tw.py` |
| 量化迴圈（RD-Agent(Q)） | 因子和模型輪流研究 | 只有上游版本，沒有台股版 |

模型迴圈裡，LLM 寫的模型分四類：

- **Tabular**：每天每檔股票一列特徵，例如多層感知器（MLP）。
- **TimeSeries**：看過去一段時間的序列，例如 LSTM、GRU、Transformer。
- **Graph**：把股票之間的關係當成圖，例如 GAT。
- **XGBoost**：樹模型。

訓練和回測都交給 qlib：
- 特徵預設是 Alpha158（158 個價量公式）。
- 標籤是隔日報酬。
- 選股策略是 TopkDropout（每天換掉排名掉下去的幾檔）。

除了 LLM 自己寫的模型，qlib 也內建很多模型。我們在台股資料上做過接線測試，只用 5 檔股票，只看能不能跑，不看績效（`rdagent/scenarios/qlib/tw_data/MODEL_SMOKE_RESULTS.md`）：

| 模型 | 結果 |
|---|---|
| LightGBM、XGBoost、線性模型、Transformer | 可以跑 |
| CatBoost、DoubleEnsemble、MLP | 參數設定錯誤，容易修 |
| LSTM、GRU、ALSTM、TCN | 資料太少時訓練流程出錯，股票變多後應該會好 |
| GATs、IGMTF、HIST | 需要更多股票或產業關係資料，沒測 |

上游的因子迴圈本身也用 LightGBM：把通過的因子丟進 LightGBM 預測報酬，再用回測結果挑最好的組合。我們的比賽版已經改成用程式評分（DECISIONS D15）。

## 2. 適不適合這次比賽

| 問題 | 說明 | 影響 |
|---|---|---|
| 評分方式對不上 | 模型迴圈的 qlib 設定是全市場選股、只買 3 檔、以台積電為基準、用收盤價成交，再用測試期績效挑最佳模型。比賽是 150 檔、買 20–30 檔、隔天用成交均價成交、只比 24 天 | 要先改成比賽版的評分程式（像因子迴圈那樣），否則選出來的模型不代表比賽表現 |
| 資料量小 | 150 檔 × 約 1,300 個交易日，大約 20 萬筆。5 日報酬天天重疊，真正獨立的樣本更少。深度模型（LSTM、Transformer）很容易過度擬合 | 頂多適合 LightGBM 或線性模型 |
| 行情反轉 | 保留期（2026-05 起）動能類和隊伍的 50/20/30 組合都失靈。用 2021–2026/04 訓練的模型，會學到這些已經失效的關係 | 需要滾動重新訓練和嚴格驗收，短期內驗證不了 |
| 選股理由 | D-Plan 每檔都要寫理由。模型的分數是很多特徵混在一起，比單一因子難解釋（可以用 SHAP 拆解，但要另外做） | 增加工作量 |
| 時程 | 10/27 開賽、11/2 v1.1。模型要訓練、驗收、再接進每日系統 | 來不及 |
| 偷看未來 | 模型架構本身不太會洩漏未來，但「用測試期績效挑模型」會 | 要沿用研究期／保留期的規則 |

**結論**：不建議在比賽前用模型迴圈。

## 3. 如果要做，比較合理的方式

1. **LightGBM 當因子組合器**：輸入只用已經檢視過的訊號，目標是預測未來 5 日報酬的排名：
   - 3 個已交易的訊號
   - 2 張保留期確認的卡片
   - 幾個基準訊號
2. **評分與測試方式**：用比賽版的評分程式。先用 2021–2023 訓練，再從 2024 起逐年往前滾動測試。
3. **先跟最簡單的組合比**：同樣的訊號，用等權排名平均當對照。LightGBM 要明顯贏過等權平均才值得用。
4. **用新資料驗收**：保留期已經看過了，所以要拿比賽期間的實盤當新的驗收資料。比賽期間只做紙上追蹤，不拿來下單。
5. **成本**：不需要 LLM，只花電腦時間。做出第一個版本大約要半天到一天。
